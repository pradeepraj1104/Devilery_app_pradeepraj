# Devilery – Full Stack Web Application

Devilery is a full-stack web application developed to practice and demonstrate modern web development concepts, including frontend development, routing, reusable components, and application structure.

## Features

* Responsive web interface
* Multiple application pages
* Navigation and routing
* Reusable UI components
* Service/product-oriented pages
* User-friendly interface
* Structured frontend application

## Technologies

* HTML
* CSS
* JavaScript
* Angular
* Node.js
* REST APIs
* Git
* GitHub

## Purpose

This project was developed as a hands-on learning project to strengthen my understanding of full-stack web development, frontend architecture, routing, components, services, and application development workflows.

## How to Run

```bash
npm install
npm start
```

Then open the local development URL shown by the application.
